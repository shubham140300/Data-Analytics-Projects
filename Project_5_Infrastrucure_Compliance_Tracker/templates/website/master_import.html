How the monthly update works

  • The app reads server names and IPs from Main Data.
  • Dated Splunk status columns become monthly snapshots. Existing history is retained.
  • The six parameter tabs are recognized. Empty tabs show no status until they contain data.
  • “Compliant to Non-Compliant” remains Unmapped, as previously selected.
  • The first upload establishes the server baseline. Later uploads show hosts absent from the previous master roster.
  • Formula-linked names and IPs are read from Main Data; status columns must contain saved values.
  • Macro-enabled files, external links, embedded files, and active controls are rejected. This is not a substitute for antivirus scanning.
