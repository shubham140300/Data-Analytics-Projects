Permission guide

  • Read opens that parameter's chart, worksheet, summary columns, and related records.
  • Write edits rows for that parameter and writes changes to the master workbook.
  • Execute imports data for that parameter and runs its permitted exports.
  • Blank username uses the user ID. The temporary password is {{ default_password }}; accounts must change it at first sign-in.
  • The owner controls workbook columns, full master imports, and access grants.
  • Access changes take effect on the user's next request.
